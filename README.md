# 삼국과 가야 디지털 역사박물관 — 프로토타입

초등학교 5학년 사회과 프로젝트를 위한 **공동 전시 플랫폼의 데모 버전**입니다.

## 현재 가능한 것

- 학생 전시물 양식 작성 및 데모 제출
- 교사 역할의 승인·수정 요청 흐름 체험
- 고구려·백제·신라·가야 전시관 관람 및 퀴즈 체험
- 브라우저 로컬 저장(같은 브라우저에서만 유지)

## 주의: 실제 수업용 서비스가 아닙니다

- 인증/권한 검사가 없습니다. 교사 메뉴도 보호되지 않습니다.
- 자료는 서버가 아니라 브라우저 `localStorage`에 저장됩니다. 다른 기기와 공유되지 않습니다.
- GitHub Pages로 배포하면 웹사이트 자체는 누구에게나 공개될 수 있습니다.
- 실제 학생 이름, 이메일, 사진, 연락처 및 비공개 수업 자료를 넣지 마세요.
- 외부 공개를 포함한 수업 운영 전에는 인증, 서버 권한 정책, 승인된 전시물만 공개하는 백엔드(Supabase 등)를 반드시 추가해야 합니다.

## GitHub Pages 배포

1. GitHub에서 새 저장소를 만듭니다 (권장 이름: `history-museum`).
2. `index.html`, `README.md`, `.nojekyll`, `.gitignore`를 저장소 최상위에 올립니다.
3. 저장소 **Settings → Pages → Build and deployment → Deploy from a branch**를 선택합니다.
4. 브랜치 `main`, 폴더 `/(root)`로 지정하고 저장합니다.
5. 배포 URL의 화면 표시를 확인합니다. 이 URL은 데모 공개용이며 학생 실데이터 운영용이 아닙니다.

## 차후 Supabase 연결 준비

향후 `projects`, `teams`, `profiles`, `exhibits`, `sources`, `quizzes`, `reviews` 등의 테이블을 도입하고, 프로젝트마다 `project_id`를 둡니다. 학생/교사 로그인, 소유권 검증, 승인된 내용만 공개하는 읽기 정책(RLS)을 적용한 후 실제 수업에 사용합니다.

기존 화면은 UI 검토용으로 유지하고, 실제 인증이 구현되면 현재 로컬 저장 및 교사 데모 승인을 교체해야 합니다.
